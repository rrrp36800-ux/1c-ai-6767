# AI development rules

Проект предназначен для разработки решений 1С:Предприятие 8.3.

## Основные правила

- Не выдумывать объекты метаданных 1С.
- Перед использованием неизвестного API проверять его через доступные инструменты.
- Использовать cc-1c-skills, если они доступны.
- После изменения BSL запускать статическую проверку.
- После изменения формы запускать валидацию формы.
- Не считать задачу выполненной только потому, что код выглядит корректно.
- Не изменять файлы вне области текущей задачи без необходимости.

## Git

- main напрямую не изменять.
- Для каждой задачи создавать отдельную ветку.
- После завершения создавать Pull Request.
- В PR указывать:
  - что сделано;
  - что проверено;
  - что не удалось проверить;
  - известные ограничения.

## Testing

Тесты должны запускаться автоматизированно.
ИИ не должен вручную перечитывать полный лог, если есть краткий machine-readable summary.
