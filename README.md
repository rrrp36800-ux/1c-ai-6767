# 1c-ai-6767

Тестовый каркас для создания среды AI-разработки решений под **1С:Предприятие 8.3**.

Сейчас репозиторий находится на этапе подготовки архитектуры. Прикладное решение 1С, бизнес-логику, обработки, справочники и документы пока не добавляем.

## Что уже есть

- `AGENTS.md` — правила работы AI-агентов и Git-процесс.
- `docs/AI_1C_tolik_qollanma.md` — исходная инструкция по подготовке окружения.
- `docs/architecture.md` — целевой development loop.
- `docs/tooling.md` — карта инструментов, подтверждённых фактов и предположений.
- `scripts/test.ps1` — честный scaffold будущего автоматического запуска проверок.
- `reports/test-summary.json` — краткий machine-readable результат текущего состояния.

## Архитектура репозитория

```text
/
├── AGENTS.md
├── README.md
├── .gitignore
├── docs/
│   ├── AI_1C_tolik_qollanma.md
│   ├── architecture.md
│   └── tooling.md
├── src/                         # будущие исходники конфигурации/расширений/обработок
├── tests/                       # будущие unit, UI и integration tests
├── scripts/
│   └── test.ps1                 # единая точка запуска автоматических проверок

    └── test-summary.json        # короткий результат для AI и CI
```

Папки `src/` и `tests/` пока содержат только `.gitkeep`: это намеренное место для будущих исходников и тестов, а не готовое прикладное решение.

## Предполагаемый development loop

```text
AI agent
  → изменение исходников
  → статический анализ BSL
  → сборка
  → unit tests
  → UI/integration tests
  → reports/test-summary.json
```

Подробное описание границ этапов и ожидаемых артефактов находится в [`docs/architecture.md`](docs/architecture.md).

## Инструменты

Основные кандидаты для следующего этапа:

- **cc-1c-skills** — навыки для AI-агентов, работающих с форматами и инструментами 1С.
- **BSL Language Server** — диагностика, статический анализ и языковые функции для BSL/OneScript.
- **YaXUnit** — будущий слой запуска автоматизированных тестов 1С.
- **Git** — ветки, коммиты и воспроизводимая история изменений.
- **GitHub Actions** — будущая оркестрация проверок в CI.
- **Локальная 1С:Предприятие 8.3** — необходима для проверки сборки и запуска тех сценариев, которые требуют среды 1С.

Точный набор команд, версии и интеграции пока не фиксируются: они должны быть подтверждены на целевой Windows-машине и в выбранной версии 1С.

## Запуск проверок

Будущая единая команда:

```powershell
./scripts/test.ps1
```

Контракт exit codes для будущего CI:

- `0` — все реально настроенные проверки завершились успешно;
- `1` — обнаружена ошибка проверки или структуры;
- `2` — проверка заблокирована или ещё не настроена (`not_run`/`blocked`).

На текущем этапе скрипт не имитирует успешные тесты и не выдаёт фальшивый `PASS`. Он формирует `reports/test-summary.json` со статусом `blocked`, пока команды BSL Language Server, сборки 1С, YaXUnit и UI/integration runner не будут реально настроены и проверены.

## Локальные требования

Для полноценного цикла потребуется локально подтвердить наличие:

- Windows и PowerShell;
- 1С:Предприятие 8.3 для операций, требующих runtime/конфигуратора;
- Java для BSL Language Server;
- Node.js там, где это потребуют выбранные AI-инструменты или тестовые утилиты;
- Git и доступ к GitHub;
- выбранных версий cc-1c-skills, BSL Language Server и YaXUnit.

Наличие этих компонентов в текущем окружении репозитория не проверялось и не предполагается автоматически.

## Правила работы

- `main` напрямую не изменять: каждая задача выполняется в отдельной ветке и через Pull Request.
- Не выдумывать объекты метаданных 1С и неизвестные API.
- После добавления BSL-кода запускать подтверждённый статический анализ.
- Не считать задачу выполненной только по виду кода.
- AI сначала читает краткий `reports/test-summary.json`, а полные логи — только при необходимости.
